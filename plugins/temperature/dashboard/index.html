LET'S SAY HELLO

让欧鲸鲸开始和你聊天

只需配置一次。密钥直接保存在本机 dsh 中，温度面板不会读取或保存密钥。

准备你自己的 DeepSeek API Key

在 DeepSeek 开放平台创建 API 密钥，模型服务可能按使用量计费。已有密钥可以直接下一步。

打开 DeepSeek 密钥管理 ↗

不要把密钥发进聊天或截图，也不用把它填在这个向导里。

在 dsh 原生设置中填写密钥

打开 DeepSeek 聊天进行配置 ↗
  1. 展开聊天页的左侧边栏。
  2. 点击左下角账号菜单，选择「设置」。
  3. 点击「模型」，在 DeepSeek 的「API 密钥」框粘贴密钥并保存。
  4. 关闭设置，选择模型和「默认工作区」，再回到这里检查。

不需要先登录 dsh 账号。看到「暂无可用模型」时，请按上面的路径检查密钥是否保存。密钥无效、余额或网络问题仍可能导致请求失败。

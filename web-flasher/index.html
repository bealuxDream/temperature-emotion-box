给开发板装上测温能力

仅适用于 ESP32-S3 DevKitC-1 兼容开发板（至少 8MB Flash），DS18B20 的 DQ 接 GPIO16。固件同时提供 USB-UART / 原生 USB 测温输出；不包含 Wi-Fi 密码或 API Key。

先确认接线

VDD → 3.3V，GND → GND，DQ → GPIO16；DQ 与 3.3V 之间使用 4.7kΩ 上拉。使用数据 USB 线，关闭其他串口监视器。

无法连接时：按住 BOOT，短按 RESET，再松开 BOOT 后重新连接。两个 USB 口的板子请参考板上 USB/UART 丝印。

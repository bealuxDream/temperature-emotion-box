# 首次使用审查与改进

2026-11-25，原公开v0.3.0：在Windows x64已有Node24.11.1、pnpm10.25.0、官方dsh0.2.2-rc.1运行时和缓存的电脑上，以全新DSH_HOME安装公开包成功。无硬件、无API Key、独立端口。首轮35秒等待超时，单独重试成功。偏好填写、持久化、跳过和认证聊天入口通过；dsh具备中文API Key引导和默认工作区。

原阻碍：缺前置环境说明；无预编译固件、图形刷写和双击入口；UART0/原生USB差异；8787冲突直接失败；串口错误只有日志，多串口和热插拔无完整引导。v0.3.0既有发布包未覆写。

v0.4.0补充Windows独立环境引导包、启动/停止入口、升级备份与失败回滚；公开无凭证固件、本地与线上刷写页；四步向导、串口诊断与动态刷新、暂停/恢复；端口冲突自动选择空闲端口。

验证分层：软件回归、独立环境安装、界面操作、实板烧录、真实温度与模型请求分别记录。新增固件不能仅凭编译成功宣称两种USB通道上板通过。后续结果见checkpoint.md。

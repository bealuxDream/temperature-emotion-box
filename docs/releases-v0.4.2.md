# v0.4.2 — 首次聊天配置向导

新用户打开温度面板、尚未检测到可选模型时，自动出现三步向导：准备 DeepSeek 密钥 → 打开 dsh，按中文菜单路径填写密钥 → 检查可选模型并试问真实温度。可稍后配置，也可随时重开。

- 密钥只填在 dsh 原生模型设置中；温度面板不读取、保存或回显密钥。
- 面板区分尚无可选模型、模型已加载、配置暂时无法确认；检测到模型不等同于密钥或 AI 回复已验证。
- 明确引导选择模型和默认工作区、发送温度查询并核对工具结果，避免把工具调用记录误当成 AI 回复验证。
- 保留国内镜像安装器、原有偏好与 17% 温度闲聊规则；标准插件和 Windows 包为 v0.4.2，公开固件保持 v0.4.0。

解压新版 Windows ZIP 后双击 Start.cmd；已有用户可直接运行新版启动器升级。标准插件通过官方 dsh plugin 命令安装。固件支持范围和实板刷写验收边界沿用 v0.4.0。

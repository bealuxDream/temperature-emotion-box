# Windows 新手包 v0.4.3

支持 Windows 10/11 x64。启动时先检查私有安装记录及 PATH 中已有组件：Node x64 ≥24.9、pnpm 10.25 以上的 10.x、官方 dsh 0.2.2-rc.1。兼容且能运行就复用，仅在缺失或不兼容时从国内镜像补装。不会覆盖过旧的全局版本。插件仍为 v0.4.2，公开固件仍为 v0.4.0，安装包下载与宣传页继续放在 GitHub。

Node 下载走 `https://npmmirror.com/mirrors/node/`（可能跳转至其 CDN），SHA-256 固定在包内，与已验证的官方发布值一致；npm、pnpm 和 dsh 安装插件的依赖都走 `https://registry.npmmirror.com`。镜像故障时提示重试，不自动改回官方源。配置仅作用于安装器及其子进程，不修改全局 npm 配置。仍需联网；DeepSeek API 请求继续访问模型服务商。

1. 解压整个 ZIP 到普通本地目录，不要在压缩包预览内运行。
2. 双击 Start.cmd，窗口显示准备进度；首次可能需要几分钟。完成后自动打开本机面板。
3. 连接开发板；尚未刷写时，点击面板的刷写入口，用 Windows Edge/Chrome 打开。暂停采集，选择设备，核对板型，再确认覆盖旧程序。
4. 刷写后断开浏览器串口、恢复采集。面板收到有效的真实温度才标记连接完成。
5. 首次面板会自动弹出聊天配置向导：准备自己的密钥 → 打开聊天并按中文菜单路径配置 → 回到面板检查模型。密钥直接填在 dsh：展开左侧边栏 → 左下账号菜单 → 设置 → 模型 → DeepSeek API 密钥 → 保存。之后在聊天选择模型和默认工作区。已有可选模型时不自动弹出；可从「打开聊天配置向导」随时重开，也可稍后配置。
6. 在聊天中问“现在真实温度是多少？”，确认查询工具和读数。没有硬件或密钥时可以打开面板，但不能完成实测/模型验证。

向导显示「已检测到可选模型」只代表 dsh 配置已加载，不能证明密钥、余额、网络或模型回复正常。没有模型时会提示准确配置路径；检查超时会显示无法确认。温度面板不读取或保存 API Key，也不会自动发送测试聊天。

日常再次双击 Start.cmd；关闭安装窗口不会停止后台服务。等待回复结束后双击 Stop.cmd 停止。
升级时解压新包，双击新版 Start.cmd。启动器仅停止自己管理的旧进程，备份旧 profile；失败恢复旧 profile。日志显示原因，个人偏好和聊天留在数据目录。升级窗口关闭不等于取消安装，请等待操作结束。
只升级启动器而标准插件版本未变时，跳过插件重装。复用的是程序文件，聊天、密钥和偏好仍保存在本项目独立数据目录；不会自动导入你原来 dsh 的账号或会话。
数据目录默认 %LOCALAPPDATA%/TemperatureEmotionBox，里面含偏好、聊天及模型凭证，请勿外发。安装窗口有按钮打开数据和日志；旧profile备份会保留。

## 卸载本项目下载的组件

双击解压目录的 `Uninstall.cmd`，或在启动窗口完成操作后点击「卸载本项目组件」。确认后先停止本项目服务，再移除下载记录中登记的私有 Node、宿主依赖、插件依赖、备份中的依赖目录及私有缓存。复用的 Node、pnpm、dsh 和全局缓存不删除；聊天、API Key、舒适偏好、工作区文件与日志默认保留。

启动成功后，数据目录的 `manager/Uninstall.cmd` 也能卸载，即使原来解压目录已移动。卸载后留下的少量设置和卸载入口用于保留个人数据；重新运行 Start.cmd 会重新检查组件并补齐缺失项。原始下载 ZIP 与解压包由你自行保管或删除，卸载器不会扫描其他下载目录。

`execution-tools.json` 记录各组件版本、路径及 managed/reused 来源，`managed-downloads.json` 记录允许清理的项目目录。旧版仅在识别到本启动器安装标记后迁移下载记录；不认识的目录不会被自动认领或删除。卸载不会沿包管理器链接进入外部目录。

硬件支持条件：ESP32-S3 DevKitC-1-N8，8MB Flash、无PSRAM或相同兼容布局；其他板型未验收。DS18B20 VDD→3.3V、GND→GND、DQ→GPIO16，DQ与3.3V之间4.7kΩ上拉，核对模块丝印。使用数据USB线。
新版公开固件不含密码，实现UART0 USB-UART（TX43/RX44）及原生USB测温输出。公开映像已编译；双通道实板刷写与两种接口仍需单独验收。刷写会覆盖旧程序及相关分区，只对专用开发板操作。
刷写连接失败：关闭串口监视器，按住BOOT、短按RESET、松开BOOT，重新选择设备。刷写后断开并恢复采集，必要时重新插拔USB。
没有串口：检查数据线和USB-UART芯片驱动，从厂商官网安装。多个设备时手动选择，自动模式不会盲目打开任意串口。
Windows来源警告或公司脚本限制，请先确认组织仓库和SHA256校验，不要关闭系统安全功能；受管设备需管理员协助。也可手动安装标准插件。

模型调用可能产生服务商费用。API Key只在dsh原生界面配置，插件不代填；舒适温度也由使用者自行提供。软件测试不代替实物测温准确度标定。

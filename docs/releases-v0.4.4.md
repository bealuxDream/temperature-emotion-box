# v0.4.4 — 组件复用与定向卸载修正版

包含 v0.4.3 的已有组件检测、缺少时补装、Uninstall.cmd、窗口卸载按钮和数据目录备用入口。修复 Windows 长短路径/目录别名不一致时，将私有组件错误标记为复用的问题；归属比较前统一解析真实路径。

启动时复用兼容且可运行的 Node x64 ≥24.9、pnpm 10.25 以上的 10.x、官方 dsh 0.2.2-rc.1，仅缺少时走国内镜像。插件仍 v0.4.2，公开固件仍 v0.4.0。标准插件版本未变时跳过重装。

卸载只清理项目下载记录内的私有运行环境、依赖及缓存，复用软件、聊天、密钥、偏好和工作区文件保留；包管理器链接不跟随到外部目录。原始 ZIP/解压包由使用者自行保管。

已实际验证外部组件复用、镜像不可用时只升级启动器、缺少兼容组件时补装、卸载后外部软件和个人偏好哈希不变、旧版安装标记迁移及重复卸载。新增路径别名回归测试。原生卸载确认窗口仅解析检查，自动验收使用隔离 worker；本轮未刷写固件或发送模型请求。

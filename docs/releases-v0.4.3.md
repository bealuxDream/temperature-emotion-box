# v0.4.3 — 复用已有组件与定向卸载

Start.cmd 先检查已有运行环境，兼容且能运行就直接复用；只从国内镜像补齐缺少的组件。Windows 启动器升级至 v0.4.3，标准插件保持 v0.4.2，公开固件保持 v0.4.0。

- Node x64 ≥24.9、pnpm 10.25 以上的 10.x、官方 dsh 0.2.2-rc.1；检查私有安装记录与 PATH 可发现的安装目录，不搜索整块磁盘。
- 记录组件来源、版本与路径；插件已安装且版本相同时跳过重装，只升级启动器也可复用。
- 新增 Uninstall.cmd、窗口卸载按钮及数据目录 manager/Uninstall.cmd；只移除本项目登记的下载依赖和私有缓存。复用的软件、聊天、密钥、舒适偏好和工作区文件保留。
- 卸载按明确目录记录执行，拒绝越界和外部目录认领，包管理器链接只解除链接，不进入外部目标。
- 下载仍走国内镜像；不修改全局软件或全局 npm 配置。复用已有 dsh 程序不等于自动导入它原有的配置和聊天，本项目继续使用独立数据目录。

验证：真实现有 Node/pnpm/dsh 复用后能启动，无新增私有 Node/dsh；禁用下载地址时只升级启动器仍能启动，插件不重装。缺少兼容 Node/dsh 时补装且保留现有 pnpm；卸载后下载目录移除，外部组件和个人偏好哈希不变。另有越界记录、外部链接目标保护与重复卸载验证。未执行新固件刷写或模型请求。
